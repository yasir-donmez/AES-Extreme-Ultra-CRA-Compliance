# AES Extreme Ultra – CRA Uyumluluk Çalışması

Bu depo, AES Group'un **AES Extreme Ultra** nesting CNC router makinesi için **AB 2023/1230 Makine Tüzüğü** ve **CRA (Siber Dayanıklılık Yasası – Cyber Resilience Act)** kapsamındaki uyumluluk çalışmasını içerir. Çalışma, *Güncel Konular* dersi kapsamında hazırlanmıştır.

## Planlanan Lab Föyleri

| Lab | Konu |
|-----|------|
| LAB01 | Emniyet Mimarisi & STO (Safe Torque Off) |
| LAB02 | Zone-Conduit Modeli (IEC 62443) |
| LAB03 | Risk Kaydı |
| LAB04 | Güvenli Uzaktan Erişim |
| LAB05 | SBOM & CVE Yönetimi |
| LAB06 | CRA Olay Müdahalesi (24 saat / 72 saat / 14 gün) |
| LAB07 | Yapay Zeka (AI) Emniyet Yönetişimi |

## Dizin Yapısı

- `lab-reports/` – Lab föylerinin PDF dosyaları bu klasöre eklenecektir.
